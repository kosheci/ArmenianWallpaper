# Astuats-Arasce 1.4 — восстановленный проект

Основан на исходниках, восстановленных из оригинального APK 1.3 через JADX. Сохранены оригинальные отрисовщик, карта, надпись и аревахач.

Изменения: карта скрыта до двойного касания; двойное касание переключает постоянное отображение карты; снижена яркость центральной искры, усилена читаемость надписи. Включён модуль VisualEffects14.java для дальнейшей интеграции.

Сборка: Gradle 8.7+, JDK 17, Android SDK 35; команда `gradle assembleDebug`. Это исходный проект, НЕ проверенный установочный APK. Восстановленный JADX Java-код может потребовать исправлений компиляции.

Важно: новая подпись APK будет отличаться от подписи 1.3; для установки может потребоваться удаление старой версии после сохранения настроек.
