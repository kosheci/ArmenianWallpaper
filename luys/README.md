# Astuats Arasce · ԼՈՒՅՍ

Живые обои с аревахачем, армянской надписью, картой, небесной орбитой, приблизительной фазой Луны и индикатором заряда. Двойное касание показывает или скрывает карту. Доступны спокойный и выразительный режимы и отдельные переключатели эффектов.

Сборка: JDK 17, Android SDK 35, Gradle 8.7, команда `gradle assembleDebug`. Тестовый APK подписывается debug-ключом. Идентификатор приложения `am.arasce.wallpaper.luys` отличается от исходной версии, что позволяет установить приложения рядом. Версия требует проверки на устройстве; для выпуска необходимы собственный стабильный ключ подписи и тестирование.
